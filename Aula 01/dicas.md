# Dicas do VSCode

## Atalhos no VSCode

- CTRL + ; Cria uma linha de comentário

## Configurações do VSCode

- Alterar tema: Arquivo / Preferências / Temas / Temas de Cores
- Alterar icones: Arquivo / Preferências / Temas / Temas do Icone de Arquivo
- Abrir terminal: ... / Terminal / Novo Terminal

# Comandos python

print() - mostra alguma informação na tela
input() - pede algo para o usuário


# Variaveis

- Nome, no python usar snake_case, começar com letra
- Valor, é o valor que passamos para a variavel
- Tipo, pode ser str (caracter alfanumerico), int (inteiro), float (numero com decimal) e bool (true/false)
